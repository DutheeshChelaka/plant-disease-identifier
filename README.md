# 🌱 PlantMD - AI Plant Disease Identifier

AI-powered plant disease detection system using deep learning with PyTorch.

## Project Goal

Build a deep learning model from scratch that identifies 38 different plant diseases from leaf images with 95%+ accuracy.

## Technologies

- **Python 3.13**
- **PyTorch** - Deep Learning Framework
- **FastAPI** - Backend API
- **HTML/CSS/JavaScript** - Frontend

## Dataset

- **PlantVillage Dataset**
- 54,000+ images
- 38 disease classes
- 14 crop species
